# Decision: every arm runs once, two blind graders, the lower value published, at least one loss in the headline

Recorded by `13-PARTNERS.md` sections 2.6 and 2.7.

## The decision

Four rules that fix the report's measurement discipline before any run happens: every arm runs exactly
once, no best-of-N on either side, no re-run replacing a recorded one. Two blind graders per task with both
sheets published and where they disagree the **lower** value is the figure with the spread beside it. At
least one loss appears in the report headline.

## The alternative rejected

Best-of-N on either arm. Letting a failed run be re-run out of the record. Averaging the two graders or
having one grader decide alone by design. Reporting only the wins.

## Why

A best pick is a selection effect wearing a measurement's clothes and it flatters whichever side gets the
retries. A failed run published with its error is data.

An average writes a number neither grader chose then buries the disagreement, which is itself information
about how hard the task was. The lower value cannot flatter us, which is the property that makes the number
worth reading.

Five clean wins reads as manufactured. The rival's own report already carries a loss and the one number a
reviewer can argue with is the control's rate, so publishing the loss is what keeps the rest credible.
Their track is 30 percent on proven advantage plus 30 percent on services they will hire themselves, so a
report claiming a win that fails when they hire it damages every other number in the submission.

## What it binds

`13-PARTNERS.md`'s report plus its evidence bundle, `10-DOCS-AND-POLICY.md`'s real-against-staged posture,
`06-QUALITY.md` which cannot count a report run as a marketplace job unless it settled as one.

## What would make us revisit it

A grader being unavailable, which section 2.7 already covers by stating what happens with one. The one-run
rule does not move: a re-run would need to be published as an additional run rather than as a replacement.
